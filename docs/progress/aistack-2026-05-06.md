## Big picture

aistack went from empty repo to a working AI capability gateway in a
single day. The path was D1 (skeleton) → D2 (TTS proxy) → D3 (ASR
in-process) → D5 (VideoCraft client switch) → D6 (LLM gateway). D4
(Web UI `/admin`) and D7 (backends/* refactor) are deferred.

Mid-day the design got repositioned from "local AI wrapper" to "AI
capability gateway" because the original framing left local-GPU
scheduling stranded in client code. See `docs/design/architecture.md`
and `docs/design/decoupling.md §11` for the rationale.

## What works (verified end-to-end)

### `POST /v1/audio/transcriptions`
- 3 ASR backends installed and proven on real audio:
  faster-whisper-small / Parakeet TDT 0.6B v3 / SenseVoice Small.
- `model="auto"` routes by `language` hint:
  CJK → SenseVoice, European → Parakeet, else → Whisper-small.
- Single-task GPU lock guards the endpoint; concurrent requests get
  503 + Retry-After: 5.
- Cache hot-swap: loading any `asr-main` model evicts other
  `asr-main` peers but keeps `asr-aux` (e.g. SenseVoice's VAD).

### `POST /v1/audio/speech`
- Reverse-proxy to Qwen3-TTS-12Hz-0.6B-CustomVoice running in the
  `aistack-qwen3-tts` Docker sidecar.
- Bound to `127.0.0.1:17860` host-only; never exposed externally.
- Pass-through extension fields: `task_type`, `language`,
  `ref_audio`, `ref_text`, etc.

### `POST /v1/chat/completions` *(Phase 2a / D6)*
- Reverse-proxy to Ollama on `127.0.0.1:11434`.
- Pre-flight evicts aistack's own `asr-main` cache to free VRAM.
- Auto-injects `keep_alive: "30s"` when the client omits it.
- Streaming (`stream: true`) flows back as SSE.

### `GET /v1/models`
- Aggregates ASR (import-probe) + TTS (Docker `/health`) + LLM
  (Ollama `/api/tags`).
- Each entry has a `capabilities` array (`asr` / `tts` / `llm`) so
  consumer pickers can filter by task.

### Cross-cutting
- Idle-eviction model cache: 5-minute keep_alive, daemon thread
  scans every 60s, GC + `torch.cuda.empty_cache()` on eviction.
  Configurable via `AISTACK_MODEL_KEEP_ALIVE_SEC`.
- Standard error envelope (`docs/api/errors.md`):
  `{ "error": { "kind", "provider", "message" } }` across all
  endpoints. 5 kinds: network / malformed / overflow / cancelled /
  unknown. The single-task busy-503 is a transport signal and uses
  FastAPI's stock `detail` instead of the envelope.

## GPU mode

PyTorch 2.5.1+cu121 + torchaudio 2.5.1+cu121 force-installed via
NVIDIA's CUDA index. CTranslate2 already shipped with bundled CUDA.

Verified speedups on RTX 4060 Laptop / 8 GB VRAM, 201 s English news
audio:

| Engine | CPU wall | GPU cold | GPU warm | Speedup (warm) |
|---|---|---|---|---|
| faster-whisper-small | 93 s | 14.3 s | ~10 s | ~9× |
| Parakeet TDT 0.6B    | 57 s | 25.1 s | 2.08 s | ~27× (RTF 0.01) |
| SenseVoice Small     | 27 s | 19.8 s | 5.98 s | ~4.5× |

## Known issues

### Parakeet GPU intermittent crash
On some cold loads NeMo throws:
```
Could not load symbol cudnnGetLibConfig. Error code 127
```
Binary ABI mismatch between torch 2.5.1+cu121's bundled cuDNN and
NeMo's expected symbol surface. Reproduces independently of any
recent code change. Workarounds, in order of effort:

- Force Parakeet to CPU (RTF 0.065 — still very fast).
- Try a different torch+cuDNN pairing (e.g. cu118 wheels).
- Disable cuDNN entirely with `torch.backends.cudnn.enabled = False`
  at NeMo load time — costs throughput, gains stability.

faster-whisper and SenseVoice on GPU have not exhibited this issue.

### 8 GB VRAM ceiling
All three ASR models plus their inference workspaces peak past 8 GB
together. The hot-swap policy + idle eviction prevent the most
common failure (rapid switches), but if a client triggers all three
in quick succession the worker can still OOM. Mitigations
documented in `docs/selection/runtimes.md`.

### Qwen3-TTS Docker memory hog
With `gpu_memory_utilization=0.80` the vLLM-Omni container reserves
~6.4 GB at startup. Coexistence with GPU-mode ASR is tight on
8 GB cards. Lower the value in `docker/tts_qwen3/docker-compose.yml`
when running on tighter hardware.

## How to operate

### Run locally

```bash
cd D:\My_Prjs\dosmoon-aistack
scripts\dev.bat              # starts uvicorn at 127.0.0.1:11500
                              # exports HF_HOME, MODELSCOPE_CACHE,
                              # NEMO_CACHE_DIR pointing at D:\AI_Models\
```

Optional ASR extras (not all needed):
```bash
uv pip install -e ".[asr-fasterwhisper]"   # always recommended
uv pip install -e ".[asr-parakeet]"        # adds NeMo (heavy)
uv pip install -e ".[asr-sensevoice]"      # adds FunASR
```

GPU mode (force-reinstall torch from CUDA index):
```bash
uv pip install --reinstall-package torch --reinstall-package torchaudio \
    --index-url https://download.pytorch.org/whl/cu121 torch torchaudio
```

TTS Docker:
```bash
cd docker/tts_qwen3 && docker compose up -d
```

### Verify

```bash
curl http://127.0.0.1:11500/health
curl http://127.0.0.1:11500/v1/models
curl http://127.0.0.1:11500/docs       # FastAPI Swagger UI
```
